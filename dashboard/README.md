# Family & Caregiver Dashboard

## Purpose

A lightweight, accessible web dashboard providing real-time location tracking, cane battery status, emergency/fall alerts, and activity logs to family members and caregivers.

## Key Planned Features

1. **Live Map View**: Real-time Leaflet/Mapbox/Google Maps view plotting cane GPS coordinates.
2. **Alert Banner**: Push alerts for emergency SOS triggers, detected falls (MPU6050 trigger), or low battery warnings.
3. **Status Overview**:
   - Connection status (Online / Offline / LoRa).
   - Battery level estimate.
   - Last known timestamp.
4. **Minimal Setup**: Lightweight vanilla HTML5/CSS/JavaScript or lightweight Vue/React single-page application connecting to Firebase or a REST API.
