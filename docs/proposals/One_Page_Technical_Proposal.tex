\section{1. Problem Statement}
Visually impaired individuals face persistent safety hazards from undetected low-hanging or ground-level obstacles and emergency falls. Existing Electronic Travel Aids (ETAs) often exceed \$500 USD (LKR 150,000+), rely on continuous cloud connectivity for basic hazard detection, and emit overwhelming audio spam that obstructs natural hearing. There is an urgent need for an affordable, offline-safe smart cane providing intuitive tactile guidance and caretaker emergency bridging.

\section{2. Proposed Solution}
\textbf{IntelliCane} is a low-cost (LKR 2,800 bench electronics), multimodal mobility aid combining an offline embedded safety reflex on the cane with an accessible companion Android application (\texttt{com.example.intellicane}):
\begin{itemize}
    \item \textbf{Offline Safety Reflex (ESP32-C3):} Sub-50\,ms deterministic loop. An HC-SR04 ultrasonic transceiver detects forward hazards up to 4\,m, driving a 3-pin vibration motor via 200\,Hz LEDC PWM that scales smoothly between 60\,cm and 10\,cm. An MPU6050 6-axis IMU detects cane tilt ($>65^\circ$) to trigger an emergency buzzer, with auto-recovery ($<30^\circ$).
    \item \textbf{Android Mobile App (\texttt{application/}):} Connects over BLE 5.0 (Nordic UART Service) and features two modes: \textit{Blind User Mode} (accessible status and connection monitoring) and \textit{Caretaker Mode} (real-time telemetry terminal, Firebase push notifications, and live OpenStreetMap tracking utilizing the phone's native A-GPS---eliminating the cost, power, and indoor blind spots of a standalone hardware GPS).
\end{itemize}

\section{4. Current Progress \& Verification}
\begin{itemize}
    \item \textbf{Physical Hardware Bench Build:} Assembled and verified with ESP32-C3 SuperMini, direct-wired HC-SR04 Echo (GPIO 1), GY-521 MPU6050, 3-pin vibration motor, and buzzer.
    \item \textbf{Proportional Haptics:} 200\,Hz LEDC PWM verified ramping smoothly from 60\,cm down to 10\,cm, remaining silent $>60$\,cm to prevent sensory fatigue.
    \item \textbf{Fall Detection \& Self-Clearing:} Tilt $>65^\circ$ triggers emergency buzzer alarm (1.5\,s debounce); restoring cane upright ($<30^\circ$) silences alarm within 200\,ms.
    \item \textbf{Resilient Multi-IC Driver:} Custom direct-register fallback driver supports clone MPU6050/6500 ICs, dual I2C addresses (\texttt{0x68}/\texttt{0x69}), and bus auto-reconnect.
    \item \textbf{Wireless BLE Telemetry:} 10\,Hz live packet broadcast over Nordic UART Service displaying connected smartphone peer MAC address.
    \item \textbf{Mobile Application Built:} Native Android Kotlin project (\texttt{com.example.intellicane}) with Caretaker Mode, OSMDroid live map, and BLE terminal.
\end{itemize}

\section{5. Technology Stack \& Budget Breakdown (Phase 1 Bench: LKR 2,800)}
\begin{itemize}

\end{itemize}

\section{6. Testing \& Validation Evidence}
\begin{itemize}
    \item \textbf{Host Unit Testing (\texttt{tests/proximity\_feedback\_test.cpp}):} 100\% pass across boundary inputs (negative, NaN, $\infty$), monotonic PWM progression, motor polarity inversion, beep transitions, and 32-bit \texttt{millis()} rollover resilience.
    \item \textbf{Bench Calibration:} HC-SR04 verified from 2\,cm to 250\,cm with $\pm 1.5$\,cm accuracy. Tilt alarm calibrated with digital protractor ($>65^\circ$ trigger, $<30^\circ$ clear).
    \item \textbf{BLE Throughput \& Thermals:} Telemetry stream validated at 10\,Hz with $<25$\,ms latency over 10\,m range. Electronics maintained $<32^\circ$C under 100\% motor duty.
\end{itemize}

\section{7. Limitations \& Risk Management}
\begin{itemize}
    \item \textbf{Ultrasonic Specular Scattering:} Sound waves can scatter on angled soft fabrics beyond 2\,m (\textit{Mitigation:} Adding Time-of-Flight laser sensor for the final).
    \item \textbf{Jumper Durability:} Prototype uses breadboard jumpers (\textit{Mitigation:} Transitioning to a custom 2-layer PCB and 3D-printed handle for final).
    \item \textbf{Phone Dependency for Cloud:} If phone battery dies, cloud tracking pauses (\textit{Mitigation:} Core obstacle avoidance and fall buzzer remain 100\% functional offline).
\end{itemize}

\section{8. Roadmap Prior to the Final (17 October 2026)}
1. \textbf{Custom PCB \& 3D Handle:} Fabricate a custom PCB and 3D-print an ergonomic handle housing with TPU vibration dampening.
2. \textbf{End-to-End Caretaker Cloud Flow:} Finalize Firebase Cloud Functions to dispatch automated SMS and push notifications on fall confirmation.
3. \textbf{Battery Optimization:} Integrate an 18650 Li-ion cell with TP4056 charge controller and implement ESP32-C3 Light Sleep for $>24$\,hour runtime.
